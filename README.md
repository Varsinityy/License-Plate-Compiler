# License-Plate-Compiler

A tool designed to build, organize, and preview custom license plates. Instead of manually renaming files and messing with folders, this tool takes your designs and automatically injects them into the exact directory structure FH5 and FH6 requires. Fully supports all FH5 game versions and partially supports FH6.

## Features

* **Automated Compilation:** Builds the full file set for EU/UK, US/MX, and FH6 Japanese plates. Fully supports doing a custom plate for a single car (FH5 1.634.818.0 and FH6).
* **3D Viewport:** Preview your textures on a real 3D plate model before putting them in-game.
* **Plate Designer:** Type custom text onto built-in US state templates or generate fully custom Japanese plates.
* **3D Map Maker:** Generate depth maps directly inside the tool with a live preview, adjustable intensity, smoothness, extrusion direction, and masking.
* **Presets:** Custom made presets ready for compilation with no outside work.
* **Plate Packs:** Share setups instantly using '.plate' files (image, map, and region). Export from History, import in the Compiler, or double-click files to launch the app (enable file association in Settings).
* **Direct Zip Merging:** Injects new plates straight into your game's `Textures.zip` archive.
* **Auto Backups:** Automatically saves backups of your original plates so you can restore them with one click.

## How to Use

1. Download `PlateCompiler.exe` from the Releases page.
2. In the **Settings** tab, select your FH5/FH6 game folders so the app knows where to save.
3. Choose your game (FH5 or FH6) and your game version at the top.
4. Use the **Designer** to build a custom plate, or drag and drop your own images into the **Compiler** tab.
5. Click **Compile Plates**.
